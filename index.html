Maze RL Simulation

A Q-learning agent with a dopamine-related state d and accumulated harm h learns which sources to use: food, social interaction, rest or two drugs. A computational hypothesis in abstract units, not a model of physiology.

Model

A weighs harm the same at any d. B weighs it less the further d is below its target. C is B without the ongoing cost of accumulated harm.

Each drug use lowers the level d rests at, which heals only slowly, and a used source needs 15 steps before it can be used again. Changing either setting resets learning.
