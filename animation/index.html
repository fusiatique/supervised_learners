3 · Reinforcement learning

The agent–environment loop

  • The agent observes a state \(s\)
  • It takes an action \(a\)
  • The environment returns reward \(r\) and next state \(s'\)
  • Goal: maximise discounted future reward
Grid world: value spreads backward from the goal as a colour wash

3 · Reinforcement learning

The Bellman equation

$$V(s) = \max_a \Big[ R(s,a) + \gamma \sum_{s'} P(s' \mid s,a)\, V(s') \Big]$$

A state's value = immediate reward + discounted value of where it leads.

Q-table cells update; δ shown as the same amber pulse as dopamine

3 · Reinforcement learning

Q-learning & the TD error

$$Q(s,a) \leftarrow Q(s,a) + \alpha\,\underbrace{\big[r + \gamma \max_{a'} Q(s',a') - Q(s,a)\big]}_{\delta}$$

The TD error \(\delta\) behaves like the dopamine prediction error.

Drug-value curve climbing without bound

3 · Reinforcement learning

Limitation for addiction

$$\delta = \max\!\big(r + \gamma V(s') - V(s) + D,\; D\big)$$

Drug as a non-compensable dopamine boost (Redish, 2004)

  • Reward is an external, fixed scalar with no internal state
  • Cannot explain satiation, tolerance or escalation
  • Drug value grows without bound
Internal-state gauge H with set-point notch H*; distance = drive

5 · Homeostatic RL

Internal state & set-point

The agent has an internal state \(H\) and a set-point \(H^*\).

$$D(H) = \Big( \sum_i \lvert h^*_i - h_i \rvert^{\,n} \Big)^{1/m}$$

Drive = distance from the set-point.

Outcome K moves H toward H*; reward = drop in drive (deprived vs sated)

5 · Homeostatic RL (Keramati & Gutkin, 2014)

Reward = drive reduction

$$r(H_t, K_t) = D(H_t) - D(H_t + K_t)$$
  • The same outcome is rewarding when deprived and neutral or aversive when sated
  • Maximising reward ≡ staying close to the set-point
Set-point notch drifts with repeated use; same dose → less reward; intake escalates

5 · Homeostatic RL (Keramati et al., 2017)

Drugs in HRL

  • Repeated intake shifts the set-point (allostasis)
  • Tolerance: the same dose yields less reward
  • Escalation: intake rises to compensate
Red harm term docks onto the HRL reward equation

6 · Adding harm

Harm as an influence on learning

$$r_t = \big[D(H_t) - D(H_t + K_t)\big] - \lambda\,\text{harm}_t$$

\(\lambda\) sets how strongly harm is weighed against homeostatic reward.

Timeline: immediate reward vs delayed harm shrinking by γᵏ; two agents' choice curves diverge

6 · Adding harm

Immediate reward, delayed harm

  • Reward arrives now; harm arrives later
  • Delayed harm is discounted by \(\gamma^k\)
  • If harm is under-weighted, use continues despite consequences

8 · Limitations of HRL

What it shows, and what it doesn't

✓ Captures

  • Satiation & dose-dependence
  • Tolerance & escalation via set-point shift
  • Bounded values
  • Unifies homeostasis and reward

✗ Misses

  • Cue-induced craving & relapse
  • Shift from goal-directed control to habit
  • Individual vulnerability
  • Social & environmental context
  • Free parameters (\(\lambda\), set-point dynamics)

9 · Conclusion

Take-aways

  1. Addiction exploits the brain's reward-learning machinery.
  2. Standard RL misses the agent's internal state.
  3. HRL grounds reward in homeostasis.
  4. Adding harm helps explain use despite consequences.
