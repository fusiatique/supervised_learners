# Fonts

Computer Modern, the LaTeX font the maths videos (`animation/maths`) use for their
formulas, so that the formulas on the pages look the same. The files are the web
version shipped with KaTeX 0.16.9 (https://katex.org), downloaded from
`cdn.jsdelivr.net/npm/katex@0.16.9/dist/fonts/`. KaTeX and its fonts are MIT licensed.

- `KaTeX_Main-Regular.woff2`, `KaTeX_Main-Bold.woff2`: upright text and numbers
- `KaTeX_Math-Italic.woff2`: math italic letters
