Learn how the maze agent learns

A beginner-friendly guide to the controls, the model, and how to interpret what you see.

Before you begin

Learning goals

  • Describe the simulation as a small world where an agent learns by choosing actions and observing scores.
  • Explain the basic concepts of state, action, reward, and learning in everyday language.
  • Use the displays to make a prediction and conduct a simple one-change-at-a-time experiment.

No programming, biology, or mathematics background is needed. Open the simulation alongside this guide. You can skip the equations on your first read: each is followed by an explanation in words.

This is a computational hypothesis, not a validated model of physiology or clinical addiction. Its states and parameter values are abstract, illustrative units. It demonstrates what can follow from these particular rules; it does not describe or predict real people.

A small glossary

Learning goals

  • Recognize the words used to describe an agent learning in an environment.
  • Distinguish what the agent knows (state), what it does (action), and the score it receives (reward).
  • Simulation / model: a simplified set of rules that a computer follows. It is like a small imaginary world, not a complete copy of real life.
  • Agent: the decision-maker in the simulation. Here, it is the face moving around the maze.
  • Environment: the maze, its walls and sources, and the rules for movement and interaction.
  • State: information about the agent’s situation right now. Here that includes its maze cell and grouped ranges of its internal variables.
  • Action: one thing the agent can choose to do, such as move one cell or use a source it is standing on.
  • Reward: a numerical score the model gives after an action. The agent uses this score to learn; it is not a real-world reward or a moral judgment.
  • Parameter: a setting that changes one of the simulation’s rules, such as how quickly d recovers.
  • Episode: one fixed-length stretch of steps. At its end the agent returns to the start, while its learning and internal state continue.

This is reinforcement learning: unlike a student given an answer key, the agent is not told the right action. It tries actions, receives scores, and gradually changes its estimates of what may work well.

1. Get oriented

Learning goals

  • Identify the agent, maze, start, walls, and source markers.
  • Use Play, Step, speed, and Reset learning, and describe what Reset does and does not erase.

The face in the maze is the agent. The letter markers are sources it can visit. In the default maze, the agent starts in the middle and the five sources are placed at the ends of separate paths, at equal distances from the start.

  • Play / Pause runs or pauses the simulation.
  • Step advances by one decision.
  • Reset learning clears what the agent has learned and restores its initial internal state. It keeps the current settings and maze layout.
  • Speed changes how many simulation steps run per second.
  • Give Drug B administers a dose at the agent’s current location. The agent does not choose the dose, and it is not a learned action or a rewarded step.

Try: Press Step a few times. One step is one decision, not one episode. The agent moves up, right, down, or left. Walking into a wall leaves it in place, but the step still passes and has the usual step cost.

Play runs continuously; while it is running, the button becomes Pause. Reset learning starts a new learner at the start with initial internal values, but keeps the current settings and maze layout.

2. Find out what the agent can do

Learning goals

  • Distinguish walking from interacting with a source.
  • Explain why reaching a source does not automatically mean the agent uses it.

At each step, the agent chooses to move one cell or—if it is standing on a usable source—to interact with that source.

  • F — Food
  • C — Social interaction
  • R — Rest
  • A — Drug A (moderate)
  • B — Drug B (potent)

At a source, interacting is a separate action from moving. The agent can stand on a source and leave without using it. If it interacts, that source is unavailable for the rest of the visit. It must leave and return before using it again. With Dependence mechanisms on, there is also a 15-step cooldown.

The built-in source rewards are 1.0 for Rest, 1.4 for Social interaction, 1.5 for Food, 3.5 for Drug A, and 5.0 for Drug B. These are abstract score units, not measured pleasure or real-world value. The built-in reward is only one part of the outcome: using a source also changes internal states, and walking to it takes steps. So the source with the largest built-in reward is not automatically the agent’s best choice. Drug B, for example, has the largest built-in reward but also has the largest modeled acute harm.

Try: Step until the agent reaches a source. Watch whether it chooses to interact or move away, then continue and see what it does next.

3. Understand the agent’s state

Learning goals

  • Explain the difference between d, its resting level, and accumulated harm h.
  • Describe what source use and passive recovery do to the internal values.

The simulation tracks two main internal quantities. You can think of d as the agent’s current reading, and the resting level as the level its reading drifts toward when it is not using a source. The target and resting level are different: the target is the level used to calculate state benefits and mood, while the resting level determines the direction of passive recovery.

  • d, the dopamine-related state: sources raise it, then it moves back toward its resting level. The neutral target is 50. The chart plots d and the resting level over time; the dashed line marks the target.
  • h, accumulated harm: harmful sources increase it and it fades gradually. The meter shows its current amount; the face also becomes paler and greyer as harm builds up.

Each normal step has two parts: source use may first raise d, then d moves toward its current resting level. Harm moves toward its previous value by retaining 98% by default, and source use can add new harm. With Dependence mechanisms enabled, each drug use also lowers the resting level; that lowered level heals very slowly. The chart’s Resting level line makes this longer-lasting change visible.

Try: Note the two chart lines and the harm meter. Click Give Drug B once or several times and watch how the agent’s state, harm, and—when dependence is enabled—resting level change. A dose is administered immediately, without advancing the step counter or being counted as an action chosen by the agent.

4. See how rewards guide learning

Learning goals

  • Explain why a source’s listed reward is not the same as the total reward for a step.
  • Identify how state change, immediate harm, accumulated harm, low state, and time spent affect the score.

The agent learns from the reward it receives after each decision. In broad terms, that reward combines:

  • the source’s built-in reward, if the agent interacted with one;
  • the benefit or cost of the change in d;
  • the immediate and accumulated harm costs;
  • an ongoing cost when d is below its target; and
  • the cost of taking a step.

In plain language, the model gives points for a source, adjusts them based on whether d moved in a helpful direction, subtracts costs associated with harm and low d, and charges a small cost for every step. This means the same source can have different total consequences depending on the agent’s current state. Harm weight also depends on the selected model and the current d.

A worked example: Suppose the agent starts at the target d = 50 with no accumulated harm and uses Food. Food adds 7, so d briefly rises to 57, then recovers toward 50 to about 56.7. With the default settings, this state increase is worth about 0.89 points; adding Food’s 1.5 source reward and subtracting the 0.02 step cost gives a total reward of about 2.37. If the agent started at a different d or had accumulated harm, the same Food action could score differently. All numbers are model units.

Optional: reward equation

r = source reward + β × [φ(dAction) − φ(d)] − λ(d) × [acute harm + ω × hNext] − κ × max(0, −φ(dNext)) − step cost

dAction is the level just after the source’s effect but before recovery; dNext is the level at the end of the step. φ is the model’s score for a particular value of d; its change after the source gives the state benefit. λ is the model’s harm weight, while β, ω, and κ set the strengths of the state benefit, accumulated-harm penalty, and low-state cost. Passive recovery does not itself earn the state-change benefit, but a low ending state can still incur a cost.

Try: Expand Learning details on the simulation and watch Reward, last step. An ordinary move normally has no source reward and still pays the step cost. Compare that with an interaction, and notice that the overall reward can be positive or negative.

5. The agent learns by trial and error

Learning goals

  • Describe a Q-value as the agent’s estimate of how useful an action is in a particular situation.
  • Explain what the learning rate, discount factor, and exploration settings do.
  • Describe when an episode ends and what the agent carries into the next one.

For each situation, the agent stores estimates called Q-values. A value is like a running guess about how much reward may come from an action in that situation. A situation includes more than the maze cell: it also includes grouped ranges (bins) of internal states and whether a source is available there.

After an action, Q-learning nudges the estimate toward the reward just received plus the estimated value of the best next action:

new Q = old Q + α × (reward + γ × best future Q − old Q)

  • Learning rate (α) controls how much each new experience changes an estimate.
  • Discount factor (γ) controls how much future estimated reward matters compared with reward now. A higher value makes future rewards count more.
  • Initial exploration (ε) sets how often the agent tries random actions instead of choosing its current favorite. Exploration decays after each episode until it reaches Minimum ε.

The agent also deliberately searches for unvisited maze cells while reachable unvisited cells remain. This guided exploration happens before its usual random-or-best action choice. Trying a random action is exploration; choosing an action with the highest current estimate is exploitation. The estimates start at zero, so early choices are not yet evidence of a settled preference.

This simulation uses a table rather than a neural network. It groups nearby values of d and h into bins so it can store a finite number of estimates. With dependence on, the drug-related deficit is also part of the state. Grouping values makes learning manageable, but means slightly different readings can share an estimate.

Episodes are fixed-length runs: reaching or using a source does not end an episode. The default step limit is twice the number of maze cells. At the limit, the agent returns to the start and begins another episode. Its learned Q-values and internal state carry over, so it can build on previous experience.

Try: Let the simulation run and watch Episodes, ε, and the bars showing sources used over recent episodes (up to the last 51 episodes, including the current one). The bars summarize recent behavior, not a promise about what the agent will choose next.

6. Compare the three models

Learning goals

  • Summarize what A, B, and C change about the reward rule.
  • Explain why the same amount of harm can have different effects on reward in different models or internal states.

Harm trade-off selects how the model weighs harm when calculating reward:

  • A: fixed trade-off weighs harm the same at every value of d.
  • B: adaptive trade-off weighs harm less when d is further below its target.
  • C: no accumulated-harm penalty uses B’s adaptive trade-off but removes the ongoing reward penalty from accumulated harm. Immediate harm costs still apply.

The displayed Harm weight λ is the multiplier on harm costs at the current d; it is not the amount of harm. In B and C it changes with d: it is lower below the target and higher above it. In A it is fixed. All three models still track accumulated harm h, but C sets its reward penalty weight to zero; it does not erase the harm state or remove immediate harm costs.

Switching models resets learning so the comparison starts with a fresh agent. A model changes how the agent scores outcomes, not the underlying effects of a source on its internal state.

Try: Run the same setup under A, B, and C. Compare the harm-weight display, accumulated-harm meter, and recent source choices. Differences can take time to emerge and individual runs may vary because the agent explores.

7. Explore dependence mechanisms

Learning goals

  • Describe the two rules enabled together by the Dependence mechanisms checkbox.
  • Distinguish the lasting change to resting level from a temporary source cooldown.

Turn on Dependence mechanisms to enable two additional assumptions together:

  1. Each drug use lowers the level d naturally returns toward. That level heals slowly.
  2. A source the agent has used cannot be used again for 15 steps, in addition to needing to leave and revisit its cell.

With dependence enabled, each drug use adds to a deficit that lowers the resting level below 50; the deficit heals very slowly. This lasting internal change is separate from the cooldown, which only temporarily blocks reuse of a source. Changing the checkbox rebuilds the model and resets learning. When it is off, drug use does not lower the resting level and sources have no extra cooldown.

Try: Turn the setting on, administer several Drug B doses, and watch the resting-level line. Then let the agent explore. Reset learning and compare with a run where the mechanism is off, keeping the model and other settings the same.

8. Run a fair experiment

Learning goals

  • Write a testable question and prediction about one simulation setting.
  • Identify what to hold constant and what to measure in a comparison.
  • Explain why one run is not conclusive evidence.
  1. Choose one question, such as “Does adaptive harm weighting change which sources the agent uses?”
  2. Record your settings and make a prediction.
  3. Change one thing—such as the model, dependence setting, or a parameter—and keep the rest fixed.
  4. Press Reset learning before comparing runs with changed parameters. Model and dependence changes reset learning automatically.
  5. Run each setup for a similar number of steps or episodes. Compare the chart, harm meter, learning details, and recent source-choice bars.
  6. Repeat if possible: exploration is partly random, so a single run may not represent every run.

Parameters: Use Show all parameters to expand sliders grouped under Internal states, Agent, and Reward. The short descriptions and “About this parameter” disclosures explain what they change. Slider adjustments affect later steps immediately, but do not erase existing learning. Reset learning before a new comparison so old Q-values do not carry over. Changing the model or dependence checkbox already triggers a reset.

For every experiment, treat the result as a consequence of this particular computational hypothesis and its chosen settings—not as evidence about real people or a clinical prediction.
