Learn how the maze agent learns

A step-by-step guide to the mechanics, math, and experiments in the simulation.

How to use this tutorial

Keep the simulation open in another tab. For each lesson, first make a prediction, then try the suggested activity and explain what you observed. You can read the lessons in order or open the sections that interest you.

This is reinforcement learning: the agent learns from rewards and experience, rather than from examples labelled with the correct action.

1. What is the simulation trying to do?

Learning goals

  • Identify the agent, environment, state, action, reward, and episode.
  • Explain that the agent learns from the consequences of its own actions.

Say: “The agent starts in a maze and chooses a direction to move. It receives a reward when it reaches an item. Through repeated attempts, it learns which moves are likely to lead to valuable outcomes.”

A state is the agent’s current cell. An action is one of four directions: up, right, down, or left. The maze and its items make up the environment. An episode is one attempt that ends when an item is reached or the step limit is reached.

Ask: “Is the agent told which direction is correct?” It is not. It learns from rewards and exploration.

2. Meet the maze, items, and controls

Learning goals

  • Find the start, walls, and items, and distinguish an item’s value from its location.
  • Use Step, Play, Reset learning, and the maze-editing tools.

Say: “The number on an item is its reward value. A larger number means more reward when the agent reaches it, but distance and the cost of each move also matter.”

Use Step to see one transition at a time, Play to run continuously, and Reset learning to clear learned values and start the agent over. The reset keeps the current maze and item placement.

Try: Locate the start and each item. Compare the item values and estimate how many moves each would take to reach.

3. What happens on one step?

Learning goals

  • Describe how a chosen action changes the agent’s cell.
  • Explain what happens when the agent tries to move into a wall.

Say: “The agent selects one of four actions. If the neighbouring cell is open, it moves there. If that cell is a wall or outside the maze, the agent stays where it is. Either way, one step has passed.”

Try: Press Step several times. Notice where the agent goes and whether it ever stays in place.

Ask: “If the agent stays still at a wall, did the action have no cost?” No: the step still counts and the step cost still applies.

4. How the reward is calculated

Learning goals

  • Calculate the reward for a move with and without an item.
  • Explain how item value and step cost can change which destination is worthwhile.

The reward on a transition is:

r = item value reached − step cost

If no item is reached, its value is zero, so the reward is just the negative step cost. With a step cost of 0.02, an ordinary move gives −0.02. Reaching an item worth 3 gives 3 − 0.02 = 2.98.

Say: “A high-value item is not automatically the best destination. Getting there takes steps, and every step has a cost. The agent learns about the total consequences of a route.”

Try: Change the step cost or item values. Before running, predict whether a nearer, lower-value item could become more attractive than a distant, higher-value item.

5. Episodes: one attempt at a time

Learning goals

  • Identify what ends an episode.
  • Explain what is reset between episodes and what the agent retains.

An episode ends when the agent reaches an item. It also ends if it reaches the simulation’s step limit, which is twice the number of grid cells. At the end of an episode, the agent returns to the start. Its learned Q-values are retained, so it can use experience from earlier episodes.

Say: “Resetting the agent’s position is not the same as resetting its learning. The agent starts a new attempt at the start cell, but it remembers its action-value estimates.”

Try: Watch the episode count and the “Last episode length” statistic. Use Reset learning and notice that the maze and item placement remain.

6. The Q-learning formula

Learning goals

  • Interpret a Q-value as an estimate for taking an action from a state.
  • Explain the roles of reward, learning rate, and discount factor in an update.

The agent stores a value Q(s, a) for each state s (cell) and action a (direction). This estimates how good it is to take that action from that cell. After an action, Q-learning updates the estimate:

Q(s, a) ← Q(s, a) + α [r + γ maxa′ Q(s′, a′) − Q(s, a)]

  • r is the reward just received.
  • s′ is the new cell reached.
  • max Q(s′, a′) is the best estimated value of an action from that next cell.
  • α is the learning rate: how much the new information changes the existing estimate.
  • γ is the discount factor: how much future estimated rewards count.

The term inside the brackets is the temporal-difference error: the difference between the new target and the old estimate.

Worked example: Suppose the old Q-value is 1, the move reward is −0.02, the best next-cell value is 2, α = 0.5, and γ = 0.98. The target is −0.02 + 0.98 × 2 = 1.94. The updated estimate is 1 + 0.5 × (1.94 − 1) = 1.47.

If an item is reached, the episode ends and the update does not include a future-value term: Q ← Q + α(r − Q). A step-limit timeout ends the episode after the update; that transition still uses the next-cell estimate.

Try: Increase the learning rate and observe that estimates can change more sharply. Increase the discount factor and discuss why future rewards may matter more.

7. Exploration and exploitation

Learning goals

  • Distinguish exploring new actions from exploiting current estimates.
  • Explain how ε changes over episodes and recognize this simulation’s guided exploration.

When the agent is not deliberately exploring, it chooses an action with the highest estimated Q-value. With probability ε, it instead chooses a random direction. This is called ε-greedy action selection.

ε = max(ε minimum, ε start × ε decayepisode number)

At the start, ε is based on “Initial exploration.” It shrinks by “ε decay per episode,” but never goes below “Minimum ε.” There is also a simulation-specific rule: before ordinary ε-greedy selection, the agent searches for a reachable, unvisited cell and moves toward one if it finds one. So early exploration is guided by coverage, not just random action selection.

Say: “Exploration gathers information; exploitation uses information already gathered. Too little exploration can miss a good route. Too much can keep the agent trying random moves.”

Try: Change the initial exploration or minimum ε, reset learning, and compare a few runs. Results can differ because random choices are involved.

8. Reading the displays

Learning goals

  • Interpret the recent-choice bars, maze shading, and policy arrows.
  • Distinguish the reward-state chart from learning rewards and Q-values.

The item-choice bars count the outcomes of the most recent 50 episodes; “None (timed out)” means no item was reached. They describe recent outcomes, not a guarantee about what the agent will choose next.

Visited open cells are shaded by relative learned state value. The arrows indicate preferred actions, but before the policy is stable the displayed arrows intentionally change and should not be read as a settled policy.

The chart titled Reward state over time shows a separate decaying level:

Rt = (1 − d) Rt−1 + ct

d is “Reward state decay” and ct is the item value consumed on that step (zero if none). This chart adds the item value but does not subtract the step cost. It is not the per-step learning reward and not a Q-value.

Ask: “Could the reward-state chart rise even if the agent had a negative reward on that step?” Yes. The chart tracks item value and decay, while learning reward also subtracts step cost.

9. Run a controlled experiment

Learning goals

  • Make a testable prediction about how one setting affects behavior.
  • Change one factor at a time and compare observations across runs.

Say: “A good experiment changes one thing at a time. If we change the maze, item values, and exploration together, we will not know which change caused the result.”

  1. Choose one question, such as: “Will increasing step cost make the agent favor a nearer item?”
  2. Record the starting settings and predict what will happen.
  3. Change only the step cost. Keep the maze and item locations fixed.
  4. Press Reset learning, then run for a comparable number of episodes.
  5. Compare episode lengths and recent item choices. Repeat if possible, since actions are partly random.

Try: Repeat the experiment with item value or ε instead. When you edit the maze or item placement, reset learning before comparing runs so the agent’s prior estimates do not carry over.

10. What should we conclude?

Learning goals

  • Recognize randomness, incomplete learning, and the effects of maze design.
  • Support conclusions with observations rather than a single outcome.

Say: “One run is evidence, not proof. Actions and tie-breaking can be random, a short run may not settle on a policy, and unreachable items cannot be chosen. The maze, step cost, item values, and exploration settings all affect what happens.”

The default layout places items in dead ends, but users can edit walls and item positions. Editing items does not itself reset the agent’s learned values, and the wall editing tools do not all reset learning in the same way. For a fair comparison after changing the layout or items, use Reset learning.

Final check: Can you explain what the agent knows (Q-values), what it wants (the reward signal), how it learns (the Q-update), how it tries unfamiliar routes (exploration), and what each display represents?

Quick reference

  • Step reward: item value reached − step cost.
  • Q-learning: old estimate moves toward reward plus discounted best next estimate.
  • α: learning rate.
  • γ: discount factor for future estimated rewards.
  • ε: probability of random action during ε-greedy selection, after the guided unvisited-cell search.
  • Reward-state chart: decaying accumulation of consumed item values, not the learning reward.
